## 🎨 CSS Features

### Gradients
```css
--primary-color: #2563eb (modrá)
--secondary-color: #10b981 (zelená)
--accent-color: #f59e0b (oranžová)
```

### Animace
- Float animace na hero dekoraci
- Hover transformace na kartách
- Smooth transitions na všech elementech

### Responsive Breakpointy
- **Desktop**: Plný layout s více sloupci
- **Tablet (768px)**: 2 sloupce, menší elementy
- **Mobile (480px)**: 1 sloupec, minimální padding

### Efekty
- Box-shadow na hover
- Transform translateY a translateX
- Opacity transitions
- Backdrop-filter efekty na boxech
